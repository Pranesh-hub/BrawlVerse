# BrawlVerse

### A Unity-Based Multiplayer Combat Game

## Overview

**BrawlVerse** is a Unity-based multiplayer combat game developed to explore core gameplay systems and real-time networking. The project focuses on responsive player controls, physics-driven combat interactions, and synchronized multiplayer gameplay using Photon PUN.

This project was completed as part of the **Summer Project ’25 “BrawlVerse”**, under the mentorship of the **Game Development Club, IIT Kanpur**.

---

## My Contribution

### Gameplay, Combat & Networking (C#)

- Implemented smooth **player movement** and responsive controls
- Integrated advanced **camera systems** using Cinemachine
- Designed and implemented **physics-based combat mechanics**, including:
  - Push
  - Grab
  - Kick
  - Headbutt
  - Dodge
  - Roll
  - Uppercut
- Built a **modular State Machine architecture** to manage player actions and transitions
- Integrated a reusable **health system** shared across gameplay components
- Synchronized **multiplayer animations and combat logic** using Photon PUN with RPCs
- Ensured consistent gameplay experience across all connected clients

## Multiplayer Systems & UI
- Gained experience in **network optimization**, minimizing bandwidth usage by synchronizing only essential gameplay data while preserving a smooth and responsive multiplayer experience.
- Dynamic **health bars** with real-time updates
- Lobby and **waiting room** flow for matchmaking
- **Match timers** and round management
- **Leaderboard system** displaying real-time player statistics
